# envox-agent

## Daily Work Log Instruction

Every day at 12:00 AM Asia/Kolkata time, review the previous calendar day's Envox project activity and append a concise dated work-log entry to `WORK_LOG.md`.

The entry should include:

- Summary of completed work.
- Timeline of important actions.
- Git commits or deployment changes, if any.
- Files or configuration changed, if relevant.
- Domain, DNS, Cloudflare, or GitHub status changes, if relevant.
- Open follow-up items.

If no project work occurred during the previous day, append a short dated entry saying no recorded project changes were found.
